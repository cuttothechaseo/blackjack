# Blackjack

A learning-first terminal blackjack game written in Python.

## Status

The project is beginning with a short exercise on moving values between a deck
and a hand. The playable game will then be built incrementally.

## Planned Version 1

- Standard 52-card deck
- Player and dealer hands
- Hit and stand actions
- Face-card and Ace values
- Dealer behavior
- Win, loss, tie, and bust outcomes
- Validated terminal input
- Repeated rounds

Advanced actions such as splitting, doubling down, insurance, and surrender
are outside the initial scope.

## Learning Focus

- Function-to-function data flow
- Multiple interacting collections
- Mutation and return values
- Non-trivial hand-value calculations
- Loops with clear stopping conditions
- Organizing one round separately from the full game

See `LEARNING_STYLE.md` for the teaching approach and `BLACKJACK_PROJECT.md`
for the development roadmap.

## Quick Learning Exercise

Run the preparation exercise with:

```bash
python3 learning.py
```
